# JavaScript (JS) 💛

## ¿Para qué se usa?
Es el lenguaje fundamental de la web. Originalmente diseñado para ejecutarse en el navegador (Frontend), hoy en día gracias a **Node.js** también se ejecuta en el servidor (Backend). Es indispensable para cualquier desarrollador Fullstack.

## Conceptos Clave para empezar
- Declaración de variables (`let`, `const`).
- Funciones tradicionales y de flecha (`arrow functions`).
- Manipulación de arreglos (`map`, `filter`, `forEach`).
- Asincronismo básico (`Promises` / `async/await`).
