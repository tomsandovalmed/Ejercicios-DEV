# C# (C-Sharp) 💜

## ¿Para qué se usa?
Creado por Microsoft, es un lenguaje robusto, tipado y orientado a objetos. Es el lenguaje estrella en el desarrollo empresarial de backend utilizando **.NET**, así como en el desarrollo de videojuegos (con el motor **Unity**). Muy pedido en empresas corporativas y bancarias.

## Conceptos Clave para empezar
- Sintaxis tipada (`string`, `int`, `bool`).
- Clases y Objetos (Orientación a Objetos).
- Métodos y control de flujo.
