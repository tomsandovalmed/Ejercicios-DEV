# TypeScript (TS) 💙

## ¿Para qué se usa?
Es un superconjunto de JavaScript desarrollado por Microsoft que añade **tipado estático opcional**. Hoy en día la gran mayoría de proyectos profesionales en React, Angular, Vue o NestJS exigen TypeScript porque ayuda a detectar errores antes de ejecutar el código y facilita la escalabilidad.

## Conceptos Clave para empezar
- Tipos básicos (`string`, `number`, `boolean`).
- Interfaces y Tipos personalizados (`type`).
- Tipado en funciones (parámetros y retorno).
