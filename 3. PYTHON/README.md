# 🐍 Python: Guía Teórica Básica

## ¿Qué es y para qué sirve?
Python es un lenguaje interpretado, de sintaxis muy limpia y fácil lectura. Es un pilar fundamental en el desarrollo backend (Django, FastAPI), automatización de tareas (scripting) y la herramienta preferida para Inteligencia Artificial y Ciencia de Datos.

## Conceptos Clave con Ejemplos

### 1. Variables y Tipos de Datos
En Python no necesitas declarar el tipo de variable explícitamente:
```python
nombre = "Camila"      # String (texto)
edad = 24              # Integer (entero)
precio = 19.99         # Float (decimal)
es_estudiante = True   # Boolean (verdadero/falso)

###2. Estructuras de Control (if / else)
La sangría (indentación) en Python determina los bloques de código:

if edad >= 18:
    print("Es mayor de edad")
else:
    print("Es menor de edad")

###3. Colecciones (Listas y Diccionarios)
# Lista (colección ordenada)
frutas = ["Manzana", "Plátano", "Naranja"]

# Diccionario (clave: valor)
persona = {"nombre": "Camila", "rol": "Dev Junior"}
