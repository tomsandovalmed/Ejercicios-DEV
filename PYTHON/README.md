# Python 🐍

## ¿Para qué se usa?
Python es un lenguaje interpretado, de alto nivel y muy legible. En el desarrollo Fullstack y backend se utiliza fuertemente gracias a frameworks como **Django** y **FastAPI**. También es el rey absoluto en **Inteligencia Artificial, Ciencia de Datos, Automatización y Scripting**.

## Conceptos Clave para empezar
- Variables y tipos de datos (int, float, str, bool).
- Estructuras de control (`if`, `for`, `while`).
- Funciones (`def`).
- Estructuras de datos (Listas, Diccionarios).
